import Derived from '@architecture-model/editable-metadata/Derived.astro'
import people from '../../../../model/people.json'

export const whoLeft = (element) => {
  const handles = ['integratedBy', 'experts', 'contributors', 'administrators'].flatMap((key) => element.getMetadata(key) ?? [])
  const gone = people.filter((person) => person.left && handles.includes(person.value)).map((person) => person.label)
  return gone.length ? gone : 'nobody'
}

When the last person who knows an integration leaves, nothing happens at first. Months later it fails, and only then does anyone find out that nobody still here knows how it works or has the login to the vendor's account. With the [people fields](../../who-to-ask/) filled in, you can check for this before it happens: list the systems, ours or external, where most of the people recorded for them have left.

## 1. Mark who has left

When someone leaves, keep their entry in `model/people.json` and add the date:

```json
[
  { "value": "igor", "label": "Igor Morozov" },
  { "value": "dana", "label": "Dana Kim", "left": "2026-05-01" }
]
```

Don't remove their handle from the systems: this recipe needs to know who used to work on each one, and pages still show the handle as their name.

## 2. Ask the agent for the list

> Using model/people.json and the people fields in the model, list every system, ours and external, where everyone in `experts` or `administrators` has left, or where most of the people across its people fields have. For each, show who has left, who is still here, and which systems and containers reference it.

The agent reads the people fields with the `likec4` MCP tool `query-by-metadata` and what references each system with `query-incomers-graph`. Add the systems whose `peopleConfirmed` date is more than about six months old as well: their fields may be out of date, so nobody knows whether their people are still here.

## 3. Find new people for each system

- **No experts left:** pick someone from the remaining contributors, or from a team that uses the system, to learn it, by working with whoever is still here or by reading the code that integrates it.
- **No administrators left:** move the vendor account, keys and billing to someone still here. Do this first: until then, nobody can rotate a leaked key or open a support ticket.
- **Most contributors left:** the system needs people who can review changes to it; add whoever starts working on it.

Then record the new people in the fields and set `peopleConfirmed` to today.

## On a system's page

A derived value shows who has left on the system's own page, so it is visible without asking:

```mdx
import Derived from '@architecture-model/editable-metadata/Derived.astro'
import people from '../../../../model/people.json'

export const whoLeft = (element) => {
  const handles = ['integratedBy', 'experts', 'contributors', 'administrators'].flatMap((key) => element.getMetadata(key) ?? [])
  const gone = people.filter((person) => person.left && handles.includes(person.value)).map((person) => person.label)
  return gone.length ? gone : 'nobody'
}

Who has left: <Derived of="stripe" value={whoLeft} />
```
