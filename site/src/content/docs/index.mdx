Tools for documenting software architecture as a [LikeC4](https://likec4.dev/) model, with a documentation site generated from it. This site is built with them: its pages, diagrams and tables come from a model of the toolkit itself.

```bash
npm create @architecture-model my-architecture
```

See [Start a repository](start/) for what that gives you.
